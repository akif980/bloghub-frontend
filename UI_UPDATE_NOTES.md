# BlogHub Modern UI Update

This project was updated with a modern visual UI layer only.

## What changed
- Updated `src/index.css` with a new responsive design system.
- Added glassmorphism cards, modern gradients, improved spacing, typography, buttons, forms, post cards, user cards, comments, footer, and mobile behavior.

## What was kept unchanged
- React page/component structure
- Routes
- API service files
- State logic
- Authentication/backend connection behavior
- Existing assets

## Run locally
```bash
npm install
npm run dev
```

## Note
The sandbox build could not be completed because the uploaded `node_modules` folder is missing Vite/Rolldown native optional dependency bindings. Running `npm install` locally should restore the correct platform dependency.
